## Machine-callable surface

Actively ships exactly one machine-callable API surface, and it is an MCP server.

- **MCP endpoint: `https://api.actively.ai/mcp`** — a LIVE hosted (remote) Model
  Context Protocol server named "Actively Intelligence MCP". Transport is
  streamable HTTP; a legacy SSE path exists at `/mcp/sse`. There is no stdio or
  npx package — the server is remote-only.
- **Authentication: OAuth 2.1**, authorization code + PKCE (S256), bearer token in
  the `Authorization` header. Authorization server: `https://auth.actively.ai`.
  Dynamic client registration (RFC 7591) is supported at
  `https://auth.actively.ai/oauth2/register`, so an MCP client can register
  itself with no prior contact with Actively. A human Actively account is still
  required to consent.
- **Tools: UNKNOWN.** `tools/list` returns HTTP 401 (`invalid_token`). The tool
  names and input schemas require an authenticated introspection and are NOT
  listed here, because Actively publishes them nowhere else.
- **Scopes:** only the OpenID Connect quartet is advertised — `openid`, `profile`,
  `email`, `offline_access`. No resource-specific scopes exist.
